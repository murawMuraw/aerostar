Real-Time Balloon Flight Around Earth

Aerost.art is an experimental real-time balloon flight simulator that visualizes atmospheric movement using live wind data.

Choose any location on Earth and launch a virtual high-altitude balloon that travels according to real weather conditions and global wind patterns.

The project combines interactive maps, atmospheric simulation, real-time weather APIs, and Earth visualization technologies to create a unique global flight experience.
